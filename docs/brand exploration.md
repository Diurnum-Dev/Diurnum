A few naming directions feel especially strong for this product.

My favorite: Ledgerly.

It sounds friendly, modern, and approachable without feeling unserious. It hints at ledger/accounting, but does not trap you in Beancount-specific terminology. It could grow from a Mac app into sync, collaboration, reports, and AI.

Other strong options:

|            |                                                                         |
| ---------- | ----------------------------------------------------------------------- |
| Name       | Why it works                                                            |
| Ledgerly   | Friendly, memorable, approachable accounting                            |
| Tally      | Simple, elegant, financial, very product-like; may be hard to trademark |
| Pennyworth | Warm, charming, personal; maybe less business-oriented                  |
| Beanwise   | Beancount nod + AI intelligence; a little playful                       |
| Clearbooks | Strong positioning, but likely crowded/trademark-risky                  |
| Balance    | Beautiful and obvious, but probably impossible to own                   |
| Ledgerline | Suggests plain text, traceability, and reporting                        |
| OpenLedger | Clear and trust-oriented, but generic and possibly crowded              |
| Fiscalist  | Professional, distinctive, but slightly cold                            |
| Countwell  | Friendly, trustworthy, accounting-adjacent                              |
| Trueledger | Strong trust/auditability signal                                        |
| Bookwise   | AI + bookkeeping; approachable                                          |
| Beanbase   | Developer-friendly, Beancount-adjacent                                  |
| Ledgr      | Modern, short, but stylized names can feel startupy                     |
| Plainbooks | Directly communicates plain-text books                                  |
| Northbooks | Calm, premium, trustworthy; less literal                                |

My top five would be:

1. Ledgerly
2. Trueledger
3. Bookwise
4. Ledgerline
5. Plainbooks

For the product you’ve described, I’d avoid names that are too AI-forward, like BookGPT or LedgerAI. The durable value proposition is not “AI accounting.” It is trusted, local-first, open-ledger accounting with AI help.

A name like Ledgerly or Bookwise gives you room to make the AI feel like a natural capability rather than the whole brand.
